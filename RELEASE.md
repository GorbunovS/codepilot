# CodePilot — краткая инструкция по установке

## 1. Скачать

Откройте страницу релизов и скачайте файл для вашей системы:

- **macOS**: `CodePilot-macOS.pkg`
- **Windows**: `CodePilot-Setup.exe`

https://github.com/GorbunovS/codepilot/releases/latest

## 2. Установить

### macOS

1. Откройте скачанный `.pkg` и пройдите установку.
2. При первом запуске macOS может показать предупреждение: приложение не может быть открыто, потому что разработчик не идентифицирован.
3. Откройте **Системные настройки → Конфиденциальность и безопасность** и нажмите **«Всё равно открыть»** рядом с сообщением о CodePilot.

### Windows

1. Запустите `CodePilot-Setup.exe` и пройдите установку.
2. При необходимости подтвердите запуск в диалоге SmartScreen: **«Подробнее» → «Выполнить в любом случае»**.

## 3. Запустить

- **macOS**: запустите CodePilot из папки **Программы** (или Launchpad).
- **Windows**: запустите CodePilot из меню **Пуск** или с рабочего стола.

## 4. Дождаться первоначальной настройки

При первом запуске приложение откроет окно настройки:

1. **Скачиваются модели** (e5-small и Laya).
2. **Запускается PostgreSQL** — либо в Docker, либо устанавливается локально.

После появления статуса **«Готовы к работе»** откроется основное окно.

> Модели и база данных скачиваются один раз. Последующие запуски будут быстрыми.

## 5. Добавить репозиторий

В основном окне CodePilot:

1. Нажмите **«+ Добавить проект»**.
2. Выберите корневую папку вашего репозитория.
3. Дождитесь окончания индексации (панель логов внизу покажет прогресс).

## 6. Подключить агента (скилл + MCP)

### Вариант A — через веб-панель

1. Откройте карточку проекта в CodePilot.
2. Нажмите **«Установить скилл в проект»** — это создаст `.kimi-code/skills/codepilot/SKILL.md`.
3. Нажмите **«Записать .kimi-code/mcp.json»** — это настроит MCP-сервер.

### Вариант B — вручную

1. Скачайте `SKILL.md` из панели (**«Скачать SKILL.md»**).
2. Положите его в `.kimi-code/skills/codepilot/SKILL.md` внутри вашего проекта.
3. Скопируйте MCP-сниппет из панели и добавьте в `.kimi-code/mcp.json` проекта.

После этого агент сможет пользоваться инструментами `search_code`, `get_symbol`, `find_references` и `read_span` вместо grep и чтения файлов целиком.

## 7. Переиндексация после изменений

Когда вы меняете код и хотите, чтобы поиск видел актуальную версию:

- В панели CodePilot нажмите **«Запустить индексацию»** для нужного проекта.
- Или вызовите инструмент `reindex` из агента.

## Готово

CodePilot работает в фоне. Агент ходит в него через MCP и экономит токены на поиске по коду.
